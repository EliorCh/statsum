# Statistics – Interactive study guide

**Live site:** https://eliorch.github.io/statsum/

A Hebrew (RTL) interactive study guide for the **Statistics** course (סטטיסטיקה) in the Computer Science program at the Academic College of Tel Aviv-Yaffo (MTA).

Part of the [MTA CS Study Hub](https://eliorch.github.io/main/) – a collection of interactive summary and practice sites that share one design system ([`main`](https://github.com/EliorCh/main)).

**Built with:** HTML, CSS, JavaScript · hosted on GitHub Pages
